# re-ordia chat — 社内チャット

Slack のように使える、社内向けのセルフホスト型リアルタイムチャットです。
Node.js だけで動きます（外部 DB 不要。データは SQLite ファイルに保存）。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| チャンネル | 公開 / プライベートの作成、トピックの設定、参加・退出、メンバーの追加。公開チャンネルは参加前にプレビューできます |
| ダイレクトメッセージ | 1対1、グループ DM（最大9人）、自分宛てメモ |
| リアルタイム | WebSocket で即時に配信。入力中の表示、オンライン状態も表示 |
| スレッド | メッセージにスレッドで返信（右パネル） |
| リアクション | 絵文字でリアクション（もう一度押すと取り消し） |
| メンション | `@ユーザー名`、`@channel` / `@here`。入力中に候補が出ます。メンションは未読バッジに反映 |
| 未読管理 | 未読チャンネルは太字、メンション数・DM 数をバッジ表示。「新着」ラインも表示 |
| 書式 | `*太字*` `_斜体_` `~取り消し線~` `` `コード` `` ```` ```コードブロック``` ```` `> 引用`、URL の自動リンク、`#チャンネル` リンク、`:tada:` などの絵文字コード |
| ファイル共有 | クリップ / ドラッグ＆ドロップ / 貼り付けで添付（20MB まで）。画像はプレビュー表示 |
| 編集・削除 | 自分のメッセージを編集・削除（空の入力欄で ↑ キーを押すと直前のメッセージを編集）。管理者は誰のメッセージでも削除できます |
| 検索 | 閲覧できるメッセージを全文検索（`Ctrl/⌘ + K`） |
| 通知 | 自分へのメンションと DM をデスクトップ通知 |
| プロフィール | 表示名、ステータス（例: 🏠 在宅勤務中）、パスワード変更 |
| その他 | ダークモード対応、スマホ表示対応 |

## 起動方法

Node.js **22.13 以上**が必要です（組み込みの `node:sqlite` を使用）。

```sh
cd chat
npm install
INVITE_CODE=好きな合言葉 npm start
# → http://localhost:3000
```

最初にアカウントを作成した人が**管理者**になります。
2人目以降は、画面の「アカウント作成」から招待コードを入力して登録します。

### 環境変数

| 変数 | 既定値 | 説明 |
| --- | --- | --- |
| `INVITE_CODE` | （なし） | アカウント作成に必要な招待コード。**社外に公開する場合は必ず設定してください**（未設定だとアクセスできる人は誰でも登録できます） |
| `WORKSPACE_NAME` | `re-ordia` | 画面に表示するワークスペース名 |
| `PORT` | `3000` | 待ち受けポート |
| `HOST` | `0.0.0.0` | 待ち受けアドレス |
| `DATA_DIR` | `chat/data` | DB とアップロードファイルの保存先 |
| `COOKIE_SECURE` | （なし） | HTTPS で運用する場合は `1` にすると Cookie に `Secure` を付けます |

### 本番運用のヒント

- 社内 LAN の 1 台のマシン、または VPS / クラウドの小さなインスタンスで動かせます。
- インターネットに公開する場合は、nginx / Caddy などのリバースプロキシで HTTPS 化し、`COOKIE_SECURE=1` を設定してください。
  WebSocket（`/ws`）もプロキシするよう設定が必要です（Caddy は自動、nginx は `Upgrade` ヘッダーの転送設定が必要）。
- バックアップは `DATA_DIR`（`chat.db*` と `uploads/`）をコピーするだけです。
- `systemd` や `pm2` で常駐させると便利です。

> GitHub Pages は静的サイト専用のため、このチャットはホストできません（サーバーが必要です）。

## 構成

```
chat/
  server.js          HTTP API + WebSocket サーバー
  db.js              SQLite スキーマとヘルパー
  public/
    index.html       画面
    app.css          スタイル（Slack 風レイアウト、ダークモード対応）
    app.js           クライアント（フレームワーク不使用）
  test/api.test.js   API のテスト
```

## セキュリティ

- パスワードは scrypt でハッシュ化して保存
- セッションは HttpOnly / SameSite=Lax Cookie。DB にはトークンのハッシュのみ保存
- 状態を変更する API にはカスタムヘッダーを必須にして CSRF を防止。WebSocket は同一オリジンのみ許可
- ログイン試行回数を制限（15分で10回まで）
- プライベートチャンネル / DM の内容・ファイルはメンバー以外から見えない
- メッセージは DOM API で描画（`innerHTML` 不使用）＋ CSP で XSS を防止
- アップロードファイルは画像以外すべてダウンロード扱い（`nosniff` 付き）
