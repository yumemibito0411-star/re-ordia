# RE:ORDIA

Redefine Ordinary — 日常を再定義する美容イベント の公式サイト（静的LP）。

- `index.html` … ページ本体
- `css/style.css` / `js/main.js`
- `images/` … 画像（未配置の枠は仮グラデーションで表示）
- `docs/image-prompts.md` … ChatGPT / Canva での画像制作ガイド

## 公開前にやること

1. `docs/image-prompts.md` に沿って画像を作成し `images/` に配置
2. 公式LINE URL（https://lin.ee/PXLjVZ7）は `index.html` 内のリンクに設定済み

ブラウザで `index.html` を開けばそのまま確認できます。
